# Bangla Bot: Kolkata Dialect (Cholitobhasha) Tutor

Developer guide and architecture reference for the `bangla-bot` repository.

## Project Overview
`bangla-bot` is an interactive Bengali language learning application tailored to the **Kolkata dialect (`Cholitobhasha`)**. It combines a frequency-ranked 5,039-word curriculum, a 5-level Spaced Repetition System (SRS), multi-mode Gemini AI tutoring sessions, and automated `gTTS` audio playback.

## Repository Architecture
- `curriculum/vocabulary/*.json` — Per-POS curriculum files (`nouns.json`, `verbs.json`, `adjectives.json`, `adverbs.json`, `pronouns.json`, `postpositions.json`, `conjunctions.json`, `interjections.json`, `numbers.json`) generated by `build_vocabulary.py`. Every item has a unique `id` (e.g., `noun_0001`, `verb_0001`, `num_0001`) and corpus `frequency`.
- `curriculum/grammar.json` — Grammar concepts (`gram_0001`..`gram_0005`) used alongside vocabulary in sessions.
- `prompts/tutor_base.md` — Base pedagogical system prompt injected into every Gemini tutor session.
- `progress_manager.py` — Manages `progress.json` (schema v2) and the 5-level SRS schedule (`1d`, `3d`, `7d`, `14d`, `30d`).
- `curriculum_manager.py` — Loads all POS JSONs and `grammar.json`, performs POS-balanced new-word selection, due+backfill review selection, and vocabulary browser filtering/pagination.
- `session_builder.py` — Builds `SessionPlan` objects for `learn`, `review`, `conversation`, and `custom` modes, assembles dynamic mode-specific system prompts, and exposes the session-scoped `submit_session_scores` Gemini tool.
- `tutor_core.py` — Gemini `GenerateContentConfig` builder (`thinking_budget=0` on Gemini 2.5/3.x), model fallback list, `<audio>` tag parsing, and `gTTS` audio caching/playback.
- `gui_practice.py` — Multi-view Flet (`1.1.2`) desktop application: Main Progress Dashboard, Filterable Vocabulary Browser, Custom Session Picker, and Active Chat Session.
- `practice.py` — Terminal CLI menu and practice loop sharing the same core modules.
- `summary.py` & `reset_progress.py` — CLI progress analytics and v2 progress reset utilities.
- `build_vocabulary.py` — Offline/API pipeline that builds `data/master_vocabulary.csv`, `data/master_numbers.csv`, and `curriculum/vocabulary/*.json` from OpenSubtitles Bengali frequency lists.

## 5-Level SRS Rules (`progress.json` v2)
- Levels: `1` (1 day), `2` (3 days), `3` (7 days), `4` (14 days), `5` (30 days).
- Newly introduced items always start locked at **Level 1** (`next_review_due = today + 1 day`) after their first session so each item gets a spaced review before advancing.
- Review items transition based on tutor scoring via `submit_session_scores`: `promote` (`+1`, max `5`), `stay` (unchanged), `demote` (`-1`, min `1`).
- The LLM never reads or writes `progress.json` or curriculum files directly; Python helper functions manage all disk I/O and inject only relevant session context.

## Running & Testing
- Start GUI: `.\.venv\Scripts\python.exe gui_practice.py` (or `.\launch_windows.ps1`)
- Start CLI: `.\.venv\Scripts\python.exe practice.py`
- View Summary: `.\.venv\Scripts\python.exe summary.py`
- Reset Progress: `.\.venv\Scripts\python.exe reset_progress.py`
- Run Unit Tests: `.\.venv\Scripts\python.exe -m unittest discover -s tests -v`
